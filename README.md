# 焊缝识别系统

基于纯视觉方案的焊缝识别系统，使用 Python 和 OpenCV 实现直线焊缝检测，支持照片、视频和摄像头输入，提供实时检测、参数模板、放大查看、自动保存等全功能 GUI。

## 功能特性

### 输入源
- **摄像头** — 实时预览与检测，支持自动保存录像
- **视频文件** — 加载 MP4/AVI/MOV 等格式，检测完毕可重新开始
- **图像文件** — 自动扫描 `data/images/` 目录，支持拖放导入、上一张/下一张浏览，加载后自动持续检测

### 检测能力
- 图像预处理：灰度转换、高斯模糊、CLAHE 对比度增强
- Canny 边缘检测 + 概率霍夫变换直线检测
- 线段过滤（长度、角度）与合并
- 所有参数可在 GUI 实时调整，带悬停提示

### 参数管理
- **可拖拽滑块** — 所有参数（含 CLAHE 限制）均支持滑块拖拽 + 数值输入
- **参数模板** — 创建/保存/删除/切换多组参数配置，本地持久化
- **一键恢复** — 随时恢复出厂默认参数
- **配置保护** — Canny 低/高阈值互锁、高斯核自动保持奇数

### 显示与交互
- 三图同屏：原图、边缘图（居中）、处理结果图（下方）
- 点击任意图片弹出**独立放大窗口**，支持：
  - 滚轮缩放（0.8×–3.0×，步长 0.2）
  - 鼠标左键拖拽平移视角
  - 最大化按钮
  - 摄像头/视频源实时更新画面
- 显示选项：独立开关原图、处理图、边缘图

### 自动保存
- 勾选「自动保存」后，检测结果自动存储：
  - **摄像头/视频源** → 录制为三个独立 AVI 视频（原始帧、检测结果、边缘图）
  - **图片源** → 保存为 PNG 截图
- 一键打开保存文件夹（📂 按钮）

### 其他
- 切换输入源自动清除残留检测结果
- 支持桌面拖放图片/视频文件加载
- 操作日志记录到 `profiles_log.yaml`

## 快速开始

### 环境要求
- Python 3.8+
- OpenCV 4.x、NumPy、PyQt5、PyYAML

### 安装
```bash
git clone <repository-url>
cd weld-line
python -m venv venv
# Windows
venv\Scripts\activate
# Linux / macOS
source venv/bin/activate
pip install -r requirements.txt
```

### 启动
```bash
python main.py
```

Windows 用户也可双击 `启动程序.pyw` 直接运行。

### 使用流程
1. 选择输入源（摄像头 / 视频文件 / 图像文件）
2. （可选）切换或调整参数模板
3. 摄像头/视频源点击「开始检测」；图片源自动检测
4. 查看检测结果，可点击图片放大细看
5. 勾选「自动保存」录制检测过程

## 配置参数

| 参数 | 默认值 | 范围 | 说明 |
|---|---|---|---|
| 模糊核大小 | 5 | 1–31 | 高斯模糊降噪强度 |
| CLAHE 限制 | 2.0 | 0.1–10.0 | 对比度增强幅度 |
| Canny 低阈值 | 50 | 0–255 | 边缘检测低阈值 |
| Canny 高阈值 | 150 | 0–255 | 边缘检测高阈值 |
| 霍夫阈值 | 50 | 1–200 | 直线检测敏感度 |
| 最小线段长度 | 50 | 10–500 | 过滤过短线段的像素长度 |
| 最大线段间隔 | 10 | 1–100 | 线段合并的最大间距 |
| 角度容差 | 15° | 1–45° | 线段合并的方向容差 |

## 项目结构

```
├── main.py                     # 主入口
├── 启动程序.pyw                # Windows 快捷启动
├── config/
│   ├── default.yaml            # 默认配置
│   ├── profiles.yaml           # 参数模板数据
│   └── profiles_log.yaml       # 模板操作日志
├── data/
│   ├── images/                 # 自动扫描的图像目录
│   └── saved/                  # 自动保存输出目录
├── src/
│   ├── core/
│   │   ├── preprocessing.py    # 图像预处理器
│   │   └── detector.py         # 焊缝检测器
│   ├── input_sources/
│   │   ├── image_source.py     # 静态图像读取
│   │   ├── video_source.py     # 视频文件读取
│   │   └── camera_source.py    # 摄像头实时捕获
│   ├── gui/
│   │   ├── main_window.py      # 主窗口
│   │   └── controls.py         # 控制面板
│   ├── config/
│   │   └── manager.py          # YAML 配置管理
│   └── utils/
│       └── visualization.py    # 检测结果可视化
├── tests/                      # 测试代码
├── AGENTS.md                   # AI 协作上下文
└── README.md
```
